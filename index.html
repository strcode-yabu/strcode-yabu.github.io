ご挨拶

S.Yabunaka@strCode は鳥取県西部を中心に活動するフリーランスプログラマーです。

Web の制作を中心に業務を受注しておりますが、制作以外にも DX 化についての相談や、ご支援もできればと考えております。

また、縁あってエンジニア育成に関わらせていただくこともあり、その経験を活かした業務の展開も模索中です。

Web やテックの活用で、業務少しでもよくしていくことに、 strCode もお手伝いさせていただければと存じます。

業務内容

提供できること。

  • Web 制作

    更新や保守がしやすく、利用者からも使いやすい Web サイトの制作を行います。

  • プログラミング教育

    初学者から中級者を対象に、プログラミングのスキルを身につけるためのお手伝いをいたします。

  • DX 相談

    社内業務の DX 化について、アドバイスやご支援いたします。
